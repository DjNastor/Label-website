AFRO HOUSE FONT PACK
Curated for Afro House, Afro Tech, record-label branding, cover artwork, posters, social media, and websites.

IMPORTANT
This ZIP does not include font files. Download each font directly from its official source to ensure correct licensing and the latest version.

RECOMMENDED BRAND SYSTEM
Logo: Ojuju
Headings: League Spartan Bold
Artist Names: Montserrat ExtraBold
Track Titles: Bebas Neue
Metadata: Inter Medium
Website/UI: Manrope

INSTALLATION — WINDOWS
1. Open FONT_LINKS.txt.
2. Download the font family from the official page.
3. Extract the downloaded ZIP.
4. Select the .ttf or .otf files.
5. Right-click and choose “Install for all users”.
6. Restart Adobe, Canva Desktop, Word, or your design application.

INSTALLATION — macOS
1. Download and extract the font family.
2. Double-click the .ttf or .otf file.
3. Select “Install Font” in Font Book.
4. Restart your design application.

DESIGN NOTES
Use African-inspired display fonts mainly for logos and short titles.
Use clean geometric fonts for artist names and metadata.
Avoid using more than three font families on one artwork.
